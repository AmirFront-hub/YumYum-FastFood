YumYumGiveMeSum
YumYumGiveMeSum is an interactive food ordering app built with HTML, CSS, JavaScript, and an API to fetch and manage menu items. 
Designed as a fun and engaging way for users to explore food choices, this app simulates the experience of ordering from a food truck. 
Users can browse a dynamic menu, add items to their order, and view a live order summary.

Features:
Interactive menu: Fetches food items dynamically using an API.

Order management: Allows users to add or remove items to/from their order.

Real-time updates: Order summary updates instantly with user selections.

User-friendly interface: Clean and intuitive design using HTML and CSS.

This project demonstrates the integration of a RESTful API to manage the food menu and enhance the application's 
interactivity, giving users a realistic and dynamic ordering experience.
